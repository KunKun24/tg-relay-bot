# 克隆机器人客服工作台

## 入口与权限

- `/start`、`/admin` 打开管理面板；`/users` 打开共享客户列表；`/clear` 只清除当前操作者选择的客户及未完成配置，不影响其他客服。
- 所有者和当前附加管理员可处理客户。只有所有者能增删附加管理员，所有者不能删除自己。每次消息、按钮及提交重新检查权限，撤权后旧按钮不能继续操作。
- 主平台管理员没有隐含的克隆客户消息访问权。
- 普通客户必须通过配置的频道成员检查。检查失败、无权限或网络异常均不放行；成功结果最多缓存45秒，变更频道或验证文案立即使旧缓存失效。历史“已验证”字段不作为绕过依据。

## 客户与分流

- 客户列表可分页，支持全部客户及待回复筛选。待回复指开放工单的最近客户入站晚于最近客服成功回复；自动回复不伪装成客服回复。
- 客户详情提供选择、认领、转交、关闭、备注和禁言。认领使用原子比较，避免同时抢占；转交仅能选当前客服。关闭后客户再次咨询会重新打开。
- 选择客户只影响你自己的当前会话。直接发送内容给当前客户，或引用当前聊天中具有已登记路由的客户消息。不会根据转发来源猜测收件人，也不会使用其他聊天的同号消息路由。
- 共享分流：未认领客户发给全部客服。均衡分流：按开放客户数选择负载最小的客服，数量相同按ID稳定选择。已经分配的客户优先发给该客服；撤权后分配会被清空。
- 媒体通过 Telegram `copy_message` 复制，保护消息内容及会员表情。只有 Telegram 返回真实消息ID才保存成功记录。明确拒绝记失败；超时/网络中断记“结果未知”，不自动重试，以免重复投递。
- 新访客通知与待回复提醒分别可配置。提醒间隔最少60秒，可设提醒次数上限，运行时每分钟检查。

## 配置步骤

所有配置先形成持久化草稿，再展示预览与确认按钮。15分钟内确认有效；重复点击不会重复执行。确认前配置不生效，重启后未过期草稿仍可恢复。取消或 `/clear` 可撤销；旧确认按钮不会确认新草稿。

### 欢迎语与自动回复

- 欢迎语支持新增、查看、编辑、开关、删除、上移、下移。按顺序发送；最后一条携带底部键盘。仅普通版附加试用提示。默认24小时欢迎间隔，客户主动 `/start` 强制发送。
- 自动回复先填写 `匹配模式|关键词`，再发送内容。模式为 `contains`（不区分大小写包含）、`exact`（去两端空白后精确）、`regex`（正则，执行有超时保护）。完整内容确认前不会创建可触发规则。
- 内容支持文字、照片、视频、动画、文件、语音、音频、贴纸、圆视频、联系人和位置。保留原生文字/媒体说明实体与会员表情，原始 `<`、`&` 等字符不会当成HTML重新解释。历史配置仍按原HTML兼容。
- 预览内容后可继续配置内联按钮，自动回复还可配置独立底部键盘；无独立键盘时使用全局键盘。消息含内联按钮和底部键盘时分两条发送以保留两者。
- 内联按钮每行一组，同一行多个按钮用 `&&`；格式 `名称|https://example.com` 或 `名称 - https://example.com`。名称可加 `#p`、`#g`、`#r` 设置颜色，可直接附会员表情实体。`无` 清空按钮。拒绝危险URL。

### JSON配置

面板“修改”后发送对应JSON，检查预览再确认：

```json
{"enabled":true,"per_row":2,"buttons":[{"text":"咨询","color":"primary","emoji_id":""}]}
```

底部键盘颜色为 `default`、`primary`、`success`、`danger`；会员图标ID用数字字符串，也可在输入中直接附真实会员表情。

```json
{"notify":true,"reminder_enabled":true,"reminder_seconds":1800,"reminder_limit":3}
```

访客通知与提醒独立开关。

```json
{"add":[123456],"remove":[]}
```

附加管理员仅所有者提交可生效。

```json
{"channel_id":"@频道","channel_link":"https://t.me/频道","verify_text":"请先加入频道"}
```

频道验证启用时检查机器人与操作者在频道中的管理员权限；`channel_id` 空字符串关闭。

```json
{"mode":"balanced"}
```

客服分流另一个值为 `shared`。

### 过滤、指令与黑名单

- 过滤规则支持新增、编辑、开关和删除。JSON示例：`{"pattern":"广告","mode":"contains","action":"mute","duration_seconds":3600}`。动作 `warn` 警告并拦截当前消息；`block` 永久拉黑；`mute` 限时禁言。正则错误或超时不会阻塞消息循环。
- 指令先发送 `名称|描述`，再发送回复内容；名称为1至32个小写字母/数字/下划线，不含 `/`，不能覆盖内置指令。支持查看、编辑、开关、删除。
- 黑名单显示有效记录，可按用户ID、姓名或用户名搜索。客户按钮提供1天、1周、1月（30天）、永久禁言和解禁，均需确认。限时禁言到期自动恢复；不影响其他克隆。
- 高级功能门禁应用在新建或修改时。原有欢迎语、自动回复等保持可读可用，降级不删除旧资源。普通版新增欢迎语默认上限3条、自动回复10条，实际数量由平台配置。

## 群组与频道

- 私聊管理面板“群组频道”中发送数字ID或 `@用户名`，也可由当前客服在目标群发送 `/bind`。机器人和操作者必须同时是目标管理员，预览确认才落盘。
- 每个绑定可独立启停、启用客服群、编辑/启停入群欢迎或解除绑定。仅群/超级群可作客服群；解除绑定不强制退群，不删除历史记录。
- 开启客服群后客户入站消息额外复制到该群。只有当前客服引用群内已映射消息才能回复客户。普通群成员、未绑定群及无路由引用均不能投递；普通群内容不会广播给私聊客户。
- 入群欢迎仅在已绑定且启用的群收到新成员服务消息时发送到该群，不发给私聊客户。频道可绑定管理，但 Telegram 没有普通频道订阅者的入群服务消息，不承诺订阅者逐人欢迎。
- 机器人离开或失去管理员身份会禁用对应绑定；恢复使用需重新校验并启用。

## 广播

- 进入广播列表，新广播先发送内容并预览，再确认入队。确认与任务/收件人创建同一事务，双击不会重复创建。
- 收件人仅为本克隆客户；发送由持久队列执行，支持查看进度、暂停、恢复、取消。
- 网络中断或进程在发送中退出后，部分收件人可能处于 `UNKNOWN`。系统不会盲目重发：可明确选择“重试未知”或“跳过未知”；重试前再次警告重复风险，因 Telegram 不提供发送幂等ID而不能保证严格恰好一次。
- 广播与其他发送共享每机器人/聊天限流和 Telegram `RetryAfter` 冷却。

## 测试与生产边界

`tests/test_relay_handlers.py` 使用临时SQLite和假Bot，不加载旧入口、不启动polling、不读取真实token、不更改生产数据库或发送真实客户消息。真实联调需指定测试目标并另行授权。
