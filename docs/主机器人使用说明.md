# 主机器人使用说明

主机器人用于登记、托管和管理双向机器人。主管理员固定为 `123456789`；克隆机器人的额外管理员不能使用主平台后台。

## 添加机器人

私聊主机器人发送 `/start`，选择「添加机器人」。可使用 BotFather Token，也可点击「一键创建双向机器人」，在 Telegram 官方窗口完成创建。Token 输入会先显示确认按钮，不回显密钥；确认后验证 Telegram 身份并启动。官方托管事件会自动建立持久配置任务，暂时网络失败会自动重试，无需再发送 `/start`。

同一 Telegram 机器人不会重复建档，不能用新的 Token 抢占他人的机器人。已经断开的机器人需要所有者明确恢复；已删除记录保留墓碑，旧事件不会复活机器人。配置通知没有送达时，也不能据此判断配置失败，应在「管理我的机器人」查看实际运行状态。

## 管理自己的机器人

「管理我的机器人」分页显示本人登记的机器人。设置页显示期望状态和实际状态，可查看续费、重启、更换 Token、断开、恢复、删除、所有权转移、专业版时间转移及时区。

- 重启、断开、恢复、删除都需二次确认。删除不可恢复；断开会停止收消息，恢复必须由所有者明确发起。
- 更换 Token 只能使用同一 Telegram 机器人身份的新 Token，不能把一个机器人替换成另一个机器人。密钥不会在预览或管理页显示。
- 所有权转移需要输入接收方数字用户 ID，对方必须先启动主机器人。发起方确认后，对方收到有效期 15 分钟的接收按钮；接收方再次确认后才变更归属。旧管理员、旧客服会话和旧配置草稿失效。
- 「转移专业版时间」选择本人另一个机器人，确认后把全部剩余有效时间转入目标，源机器人归零。永久会员不支持此转移。
- 时区单独使用 IANA 名称，如 `Asia/Shanghai`、`UTC`，与专业版时间转移是两个独立功能。

输入草稿和确认按钮均有 15 分钟有效期。返回或取消会清除当前草稿。所有操作在提交时再次检查当前所有者，旧按钮不能绕过转移后的权限。

## 购买与续费

套餐为 1 个月 5 USDT、3 个月 10 USDT、永久 30 USDT。打开机器人设置中的续费入口，选择套餐创建订单，付款后点击「我已支付」。开通必须由支付接口返回已支付状态；本地再次检查订单归属。支付响应若包含订单标识、金额或币种，也逐项与本地订单核对，不匹配则拒绝开通；接口缺少这些字段时，核验能力取决于支付方查询结果。重复查询已支付订单只显示结果，不重复增加时长。永久会员不会因短期套餐降级。

## 主平台后台

只有主管理员在首页看到后台入口，所有后台回调和最终提交同样检查身份。

- 文案设置包含主平台及克隆端共用文案。支持 Telegram 原生富文本和自定义表情，输入后先预览再确认。
- 按钮设置覆盖默认按钮，分别编辑文字、链接、颜色、自定义表情图标。颜色支持默认、蓝、绿、红；链接或图标输入「无」可清除。
- 「逐个修改」跳过已经修改的项目；「全部修改」包含已经修改的项目。向导可跳过，按钮向导依次编辑文字、颜色和适用的链接，均需确认才保存。
- 支付设置包括商户 ID、密钥、API、回调地址、汇率和启用状态。密钥仅显示隐藏标识，支付 API 和回调地址要求 HTTPS。
- 普通版额度默认是 5 个机器人、3 条欢迎语、10 条自动回复。调整额度只约束新增，不移除既有资源。
- VIP 功能要求开关可把指定能力改为所有用户可用，或要求有效专业版；统一能力判断作用于界面和提交。
- 用户、机器人、订单、广播任务列表均可分页。机器人平台管理的重启、断开、恢复和删除需确认；后台不展示 Token。
- 手动开通支持输入 `机器人ID 1m`、`机器人ID 3m` 或 `机器人ID forever`，预览确认后生效。

## 主平台公告与欢迎语重发

公告只投递给启动过主机器人的用户，通过主机器人发送；不会跨克隆机器人向客户发送。支持文字、图片、视频、文件及原生富文本、自定义表情，可回复一条帖子作为内容。先发送预览，点击确认后才建立 SQLite 持久任务和收件人快照。

「重发主平台欢迎语」也使用同一持久队列，包含首页按钮。任务页可以查看成功、待发、失败及结果不确定的数量，并暂停、继续或取消剩余收件人。服务重启后恢复进度，不重复发送已记录成功的收件人。

若网络错误使发送结果不确定，收件人标记为 `UNKNOWN`。管理员必须选择「重试」或「跳过」并确认：重试可能重复送达，跳过可能漏发。限流和明确未发送的临时错误由队列安排重试，不会用无限循环阻塞菜单。
