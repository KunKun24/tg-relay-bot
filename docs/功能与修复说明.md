# 功能与修复说明

版本：2.0.0；升级日期：2026-11-08。主机器人：@YOUR_BOT；主管理员：123456789。

## 多文件结构

原有 5116 行单文件已拆为 29 个 `relayapp` 模块。原入口保留为 11 行兼容启动器，正式服务运行 `python -m relayapp.runtime`。

| 模块 | 职责 |
| --- | --- |
| config、defaults、configuration | 私有环境、默认文案按钮、可调整平台配置 |
| database、schema | SQLite 连接、事务、兼容迁移和索引 |
| bots、clients、payments | 机器人归属、客户与工单、支付权益仓库 |
| formatting、network | 原生实体/媒体/按钮、共享限速、可选服务内 DNS 修正 |
| relay、clone_state、clone_ui、clone_config、clone_groups | 克隆消息、客服工作台、配置草稿、群组功能 |
| main_ui、main_sessions、main_actions、main_settings、main_admin、main_payments、main_broadcast | 主平台菜单与各业务向导 |
| managed、lifecycle | 官方托管事件、启停、身份检查、转移后的运行管理 |
| broadcast、runtime | 持久广播和主进程监督 |
| common、store、__init__ | 公共导出、仓库门面、版本 |

不动态执行旧单文件；没有通过 `exec` 包装旧业务。配置和 Token 从私有环境读取，导入模块不会启动轮询。

## 客服与客户隔离

- 所有者及当前附加管理员使用动态身份判断，额外客服不再被误判为普通客户。
- 当前客户按“克隆 + 客服”分别保存；引用消息路由按“克隆 + 管理员聊天 + 消息 ID”查找。
- 支持客户分页、待回复筛选、认领、转交、关闭、备注、共享或均衡分流。认领使用原子条件更新。
- 待回复根据客户最后入站与客服最后成功回复计算；自动回复不计成人工回复。
- 新访客通知、待回复提醒可独立配置。附加管理员被撤权后，旧按钮和草稿重新检查权限。
- 私聊消息复制仅在 Telegram 返回真实消息 ID 后记录成功。网络结果不确定时记为 UNKNOWN，不自动重复复制。

## 验证、黑名单和内容

- 强制频道验证应用于每次客户入口，检查异常不放行；不再把历史 verified 字段当作永久通行证。
- 通过验证最多缓存 45 秒，变更配置立即使旧缓存失效。
- 禁言支持 1 天、1 周、30 天和永久；到期自动恢复，并按克隆隔离。
- 欢迎语支持新增、排序、编辑、开关、删除；主动 /start 强制响应，普通版试用提示不再发送给高级版。
- 自动回复支持包含、精确、正则；完整预览确认前不创建可触发规则，正则具有超时保护。
- 支持 11 类单条内容：文字、照片、视频、动画、文件、语音、音频、贴纸、圆视频、联系人、位置。
- 保存 Telegram 原生 entities/caption_entities，按 UTF-16 验证位置，修复会员表情错位及姓名 HTML 转义问题。
- 内联按钮、全局底部键盘和自动回复独立底部键盘可配置；同一消息只能挂一种键盘，需要时分条保留两种。
- 按钮支持 primary 蓝、success 绿、danger 红、自定义表情图标。明确图标资格拒绝时仅做一次兼容降级；网络错误不触发盲重发。
- 过滤规则、用户指令、黑名单搜索、访客提醒、附加管理员和分流配置均有可提交的实现。
- 配置使用 15 分钟 SQL 草稿与一次性确认，确认提交时再次检查权限。

## 群组与广播

- 绑定群组/频道时核验操作者与机器人管理员资格；确认后落盘，解除不强制退群。
- 已启用客服群可接收客户消息副本，当前客服引用有路由的群消息才能回复。
- 已绑定群的新成员服务消息可触发群内欢迎；普通频道没有逐个订阅者入群欢迎事件。
- 主平台广播仅面向启动过主机器人的用户，克隆广播仅面向自身客户。
- 广播持久化任务和收件人，预览确认后入队；支持进度条、暂停、继续、取消、未知结果重试或跳过。
- 已记成功不重复调度，进程退出时未能确认的发送恢复为 UNKNOWN，须人工明确处理。
- 所有发送共享每个 Telegram 机器人约 20 次/秒的应用限速；同私聊约 1.05 秒，群/负 ID 约 3.1 秒。Telegram 的实际限制以 RetryAfter 为准。

## 支付、所有权与生命周期

- 订单结算和权益发放在同一事务中，订单唯一授权记录防止重复延长；并发回归验证只授予一次。
- 支付接口必须返回已支付状态；返回的订单标识、金额、币种若存在则逐一核验。没有这些返回字段时不宣称完成了该字段校验。
- 权益用秒级时间保存，历史日期按上海时区当天结束迁移；永久会员不被短期套餐覆盖。
- VIP 能力与普通版新增额度统一在界面及提交处检查，旧资源不因降级被删除。
- Token 更换先调用 Telegram 验证同一机器人身份，错误 Token 不先中断原运行。
- 所有权转移由双方确认、15 分钟有效；接收时清除旧管理员、会话、草稿和分配，并更新运行代次。
- 专业版时间转移与时区设置分离；同一所有者的有限剩余时间可转移，永久会员不支持时长转移。
- 启动、停止、重启、断开、恢复、删除和换 Token 使用同一机器人锁；期望状态与实际状态分开记录。
- 删除使用墓碑，托管旧事件不会复活已删除/断开实例。退出服务保留期望状态以便恢复。
- 临时连接失败可指数退避恢复，最多并行 2 个，退避 30 秒至 15 分钟；InvalidToken 不自动反复尝试。

## 使用入口

主机器人发送 /start，主管理员发送 /admin。克隆机器人所有者和附加管理员发送 /admin；/users 打开客户，/clear 清理本人当前选择与草稿。配置示例见两份使用说明。
